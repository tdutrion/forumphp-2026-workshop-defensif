# Workshop « PHP défensif » — v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire la v1 du planificateur de marathon cinéma (Symfony 8.1, FrankenPHP, MySQL) : une application propre, fonctionnelle et sûre dont les contrats restent volontairement implicites, point de départ de l'atelier du 8 octobre 2026.

**Architecture:** Projet Symfony « typique » en couches : entités Doctrine avec getters/setters, services applicatifs qui échangent des tableaux, repositories, contrôleurs Twig et JSON minces qui appellent les mêmes services. Pathé n'est appelé que par la commande de synchro ; le site lit la base. Un dump SQL du catalogue, préparé la veille, rend l'application utilisable sans réseau.

**Tech Stack:** PHP 8.5 (FrankenPHP 1.12.7 Alpine, worker mode, hub Mercure intégré), Symfony 8.1, Doctrine ORM 3.7 / DBAL 4, MySQL 8.4, KnpU OAuth2 Client + league providers, navikt/mock-oauth2-server, Symfony UX (Turbo, Autocomplete, Stimulus) + AssetMapper, Nelmio API Doc, PHPUnit 13 + dama/doctrine-test-bundle, PHPStan 2, PHP-CS-Fixer, PIE 1.5.

**Spec:** `docs/superpowers/specs/2026-10-04-workshop-design.md` (à lire avant toute tâche : sections 5 à 9 en particulier).

## Global Constraints

- Image de base : `dunglas/frankenphp:1.12.7-php8.5-alpine`, épinglée par digest dans le Dockerfile.
- Un seul `Dockerfile` multistage : base commune (intl, opcache, pdo_mysql via `install-php-extensions` fourni par l'image, pour les extensions livrées avec PHP ; apcu 5.1.28 via PIE 1.5.1), cible `dev` (Composer, zip, Xdebug 3.5.3 via PIE) et cible `prod` (sans Composer ni git, utilisateur `www-data`, OPcache prod).
- Symfony 8.1.*, PHP 8.5, MySQL 8.4 (`mysql:8.4`), `symfony/polyfill-php86`, `symfony/polyfill-time`.
- Identifiants générés : UUID v7 (`Symfony\Component\Uid\Uuid::v7()`). Données Pathé : le slug est la clé primaire ; la séance est identifiée par le segment `V{n}S{n}` de son `refCmd`.
- Langues : identifiants en anglais ; interface, messages d'erreur, commentaires et docs en français ; README en anglais.
- Commits : Conventional Commits en anglais, signés, auteur `Thomas Dutrion <hello@tdutrion.fr>` (déjà configuré dans le dépôt). Terminer chaque message par `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Style v1 (spec §8)** : PAS de `declare(strict_types=1)`, tableaux associatifs entre services, scalaires pour les concepts métier, retours `X|false` / `?X`, exceptions génériques (`\RuntimeException`, `\InvalidArgumentException`), entités avec getters/setters nullables, `match` sur des chaînes, `new \DateTimeImmutable()` dans les services, paramètres de config lus en chaînes. Ce style est **voulu** : ne pas le « corriger ». Le code doit néanmoins être propre, lisible, formaté (`@Symfony`) et honnête.
- **Interdits absolus** : faille de sécurité, bug connu, logique dupliquée entre web et API, état propre à un utilisateur dans un service (worker mode), test rouge, erreur PHPStan niveau 5.
- Sécurité en place dès la v1 (spec §7) : requêtes paramétrées, CSRF sur tout formulaire qui modifie un état et sur la déconnexion, échappement Twig, state + PKCE OAuth, liaison de compte seulement sur email vérifié, jetons d'API aléatoires stockés hachés, `#[\SensitiveParameter]` sur secrets et jetons, aucune redirection vers une URL fournie par l'utilisateur.
- Pathé : base `https://www.pathe.fr/api/`, User-Agent `PatheApiExplorer/1.0`, requêtes séquentielles (délai par défaut 1000 ms), arrêt de la synchro sur 403/429. Heures Pathé naïves interprétées en `Europe/Paris` (`date.timezone = Europe/Paris`).
- Règles du planificateur (spec §5) : marge 10 min, trajet = distance à vol d'oiseau à 15 km/h, option pubs = arrivée jusqu'à `time + 15 min`, jamais deux fois le même film, rayon 1–50 km (10 par défaut), 2–5 films, 3 programmes max deux à deux différents, plafond 20 000 nœuds.
- Toutes les commandes passent par Docker via le `Makefile` (jamais de PHP sur l'hôte).

## Review Focus

1. **Séance qui finit après minuit** (`endTime` = `2026-10-05 00:09:00` rangée sous la date du 4) : doit rester une séance du 4 et bloquer correctement l'enchaînement suivant. Test : Task 8 (`testChainingAcrossMidnight`) et Task 3 (`testMapsShowtimeEndingAfterMidnight`).
2. **Ville dont la position Pathé est fausse** (Dijon) : le centre doit être le barycentre de ses cinémas, sinon aucun résultat. Test : Task 9 (`testCityCentreIsTheBarycentreOfItsCinemas`).
3. **Réponse Pathé vide sous deux formes** (`[]` ou `{}`) et **404 sous forme de chaîne JSON** : la synchro doit continuer sans planter. Test : Task 3 (`testEmptyShowtimesResponseGivesNoShowtime`, `testNotFoundReturnsFalse`).
4. **Utilisateur ayant déjà vu presque tout** : moins de 3 programmes, voire aucun, avec un message explicite au lieu d'une page vide ou d'une erreur. Test : Task 9 (`testReturnsReasonWhenFewerThanThreeProgrammes`) et Task 10 (`testShowsMessageWhenNoProgramme`).
5. **Séance dont la réservation est close** (séance déjà commencée le jour J) : jamais proposée. Test : Task 9 (`testExcludesShowtimesWhoseBookingIsClosed`).

`frankenphp/docker-entrypoint.sh` (celui de symfony-docker, sans le bloc d'installation initiale) :

```sh
#!/bin/sh
set -e

if [ "$1" = 'frankenphp' ] || [ "$1" = 'php' ] || [ "$1" = 'bin/console' ]; then
	if [ -z "$(ls -A 'vendor/' 2>/dev/null)" ]; then
		composer install --prefer-dist --no-progress --no-interaction
	fi

	php bin/console -V

	if grep -q ^DATABASE_URL= .env; then
		echo 'Waiting for database to be ready...'
		ATTEMPTS_LEFT_TO_REACH_DATABASE=60
		until [ $ATTEMPTS_LEFT_TO_REACH_DATABASE -eq 0 ] || DATABASE_ERROR=$(php bin/console dbal:run-sql -q "SELECT 1" 2>&1); do
			if [ $? -eq 255 ]; then
				ATTEMPTS_LEFT_TO_REACH_DATABASE=0
				break
			fi
			sleep 1
			ATTEMPTS_LEFT_TO_REACH_DATABASE=$((ATTEMPTS_LEFT_TO_REACH_DATABASE - 1))
			echo "Still waiting for database to be ready... Or maybe the database is not reachable. $ATTEMPTS_LEFT_TO_REACH_DATABASE attempts left."
		done

		if [ $ATTEMPTS_LEFT_TO_REACH_DATABASE -eq 0 ]; then
			echo 'The database is not up or not reachable:'
			echo "$DATABASE_ERROR"
			exit 1
		else
			echo 'The database is now ready and reachable'
		fi

		if find ./migrations -iname '*.php' -print -quit | grep --quiet .; then
			php bin/console doctrine:migrations:migrate --no-interaction --all-or-nothing
		fi
	fi

	echo 'PHP app ready!'
fi

exec docker-php-entrypoint "$@"
```

```php
<?php

namespace App\Tests\Factory;

use App\Catalog\Entity\Cinema;
use App\Catalog\Entity\City;
use App\Catalog\Entity\Film;
use App\Catalog\Entity\Showtime;
use Doctrine\ORM\EntityManagerInterface;

final class CatalogFactory
{
    public function __construct(private EntityManagerInterface $em)
    {
    }

    public function city(string $slug = 'dijon', string $name = 'Dijon'): City
    {
        $city = (new City())->setSlug($slug)->setName($name);
        $this->em->persist($city);

        return $city;
    }

    public function cinema(City $city, string $slug, float $latitude, float $longitude, bool $open = true): Cinema
    {
        $cinema = (new Cinema())
            ->setSlug($slug)
            ->setName('Cinéma '.$slug)
            ->setCity($city)
            ->setLatitude($latitude)
            ->setLongitude($longitude)
            ->setOpen($open);
        $this->em->persist($cinema);

        return $cinema;
    }

    public function film(string $slug, int $duration = 100, string $title = ''): Film
    {
        $film = (new Film())->setSlug($slug)->setTitle('' !== $title ? $title : ucfirst($slug))->setDuration($duration);
        $this->em->persist($film);

        return $film;
    }

    /**
     * @param string $time heure de début, ex. '2026-10-08 14:00:00'
     */
    public function showtime(string $id, Film $film, Cinema $cinema, string $time, string $version = 'vf', ?string $reservableUntil = null): Showtime
    {
        $start = new \DateTimeImmutable($time);
        $showtime = (new Showtime())
            ->setId($id)
            ->setFilm($film)
            ->setCinema($cinema)
            ->setStartsAt($start)
            ->setEndsAt($start->modify('+'.($film->getDuration() + 20).' minutes'))
            ->setVersion($version)
            ->setStatus('available')
            ->setBookingUrl('https://s.pathe.fr/fr/'.$id.'/booking')
            ->setReservableUntil(new \DateTimeImmutable($reservableUntil ?? $start->modify('+20 minutes')->format('Y-m-d H:i:s')));
        $this->em->persist($showtime);

        return $showtime;
    }

    public function flush(): void
    {
        $this->em->flush();
    }
}
```

```php
<?php

namespace App\Tests\Integration\Catalog;

use App\Catalog\Repository\ShowtimeRepository;
use App\Tests\Factory\CatalogFactory;
use Symfony\Bundle\FrameworkBundle\Test\KernelTestCase;

final class ShowtimeRepositoryTest extends KernelTestCase
{
    private ShowtimeRepository $repository;
    private CatalogFactory $factory;

    protected function setUp(): void
    {
        self::bootKernel();
        $em = self::getContainer()->get('doctrine.orm.entity_manager');
        $this->factory = new CatalogFactory($em);
        $this->repository = self::getContainer()->get(ShowtimeRepository::class);
    }

    public function testFindCandidatesFiltersByDateCinemaSeenFilmsVersionAndBooking(): void
    {
        $city = $this->factory->city();
        $a = $this->factory->cinema($city, 'cinema-a', 47.3180, 5.0299);
        $b = $this->factory->cinema($city, 'cinema-b', 47.3124, 5.0914);
        $digger = $this->factory->film('digger-51293', 129, 'Digger');
        $verity = $this->factory->film('verity-50815', 117, 'Verity');
        $this->factory->showtime('V1S1', $digger, $a, '2026-10-08 14:00:00');
        $this->factory->showtime('V1S2', $verity, $a, '2026-10-08 17:00:00', 'vost');
        $this->factory->showtime('V1S3', $verity, $b, '2026-10-08 18:00:00');
        $this->factory->showtime('V1S4', $digger, $a, '2026-10-09 14:00:00');
        $this->factory->showtime('V1S5', $digger, $a, '2026-10-08 09:00:00', 'vf', '2026-10-08 09:20:00');
        $this->factory->flush();

        $rows = $this->repository->findCandidates('2026-10-08', ['cinema-a'], ['verity-50815'], null, '2026-10-08 10:00:00');

        self::assertSame(['V1S1'], array_column($rows, 'id'));
        self::assertSame('Digger', $rows[0]['filmTitle']);
        self::assertSame('2026-10-08 14:00:00', $rows[0]['startsAt']);
        self::assertSame('2026-10-08 16:29:00', $rows[0]['endsAt']);

        $vost = $this->repository->findCandidates('2026-10-08', ['cinema-a', 'cinema-b'], [], 'vost', '2026-10-08 10:00:00');
        self::assertSame(['V1S2'], array_column($vost, 'id'));
    }

    public function testFindAvailableDatesStartsAtTheGivenDay(): void
    {
        $city = $this->factory->city();
        $a = $this->factory->cinema($city, 'cinema-a', 47.3180, 5.0299);
        $film = $this->factory->film('digger-51293');
        $this->factory->showtime('V1S1', $film, $a, '2026-10-07 14:00:00');
        $this->factory->showtime('V1S2', $film, $a, '2026-10-08 14:00:00');
        $this->factory->showtime('V1S3', $film, $a, '2026-10-09 23:30:00');
        $this->factory->flush();

        self::assertSame(['2026-10-08', '2026-10-09'], $this->repository->findAvailableDates('2026-10-08'));
    }

    public function testDeleteForCinemasBetweenKeepsListedIdsAndOtherCinemas(): void
    {
        $city = $this->factory->city();
        $a = $this->factory->cinema($city, 'cinema-a', 47.3180, 5.0299);
        $b = $this->factory->cinema($city, 'cinema-b', 47.3124, 5.0914);
        $film = $this->factory->film('digger-51293');
        $this->factory->showtime('V1S1', $film, $a, '2026-10-08 14:00:00');
        $this->factory->showtime('V1S2', $film, $a, '2026-10-08 18:00:00');
```

```php
<?php

namespace App\Catalog\Repository;

use App\Catalog\Entity\Showtime;
use Doctrine\Bundle\DoctrineBundle\Repository\ServiceEntityRepository;
use Doctrine\DBAL\ArrayParameterType;
use Doctrine\Persistence\ManagerRegistry;

/**
 * @extends ServiceEntityRepository<Showtime>
 */
class ShowtimeRepository extends ServiceEntityRepository
{
    public function __construct(ManagerRegistry $registry)
    {
        parent::__construct($registry, Showtime::class);
    }

    /**
     * Jours (format 'Y-m-d') qui ont au moins une séance, à partir de $from inclus.
     */
    public function findAvailableDates(string $from): array
    {
        return $this->getEntityManager()->getConnection()->fetchFirstColumn(
            'SELECT DISTINCT DATE(starts_at) AS day FROM showtime WHERE starts_at >= :from ORDER BY day',
            ['from' => $from.' 00:00:00'],
        );
    }

    /**
     * Séances d'un jour dans les cinémas donnés, réservables à l'instant $now, hors films exclus.
     *
     * @param string      $date              jour, format 'Y-m-d'
     * @param array       $cinemaSlugs       slugs des cinémas à retenir
     * @param array       $excludedFilmSlugs slugs des films à exclure (déjà vus)
     * @param string|null $version           'vf', 'vost', 'vo', 'vfst' ou null pour toutes
     * @param string      $now               instant courant, format 'Y-m-d H:i:s'
     *
     * @return array lignes ['id', 'filmSlug', 'filmTitle', 'duration', 'cinemaSlug', 'cinemaName',
     *               'latitude', 'longitude', 'startsAt', 'endsAt', 'version', 'bookingUrl']
     */
    public function findCandidates(string $date, array $cinemaSlugs, array $excludedFilmSlugs, ?string $version, string $now): array
    {
        if ([] === $cinemaSlugs) {
            return [];
        }

        $sql = 'SELECT s.id, s.film_slug AS filmSlug, f.title AS filmTitle, f.duration, s.cinema_slug AS cinemaSlug,
                       c.name AS cinemaName, c.latitude, c.longitude, s.starts_at AS startsAt, s.ends_at AS endsAt,
                       s.version, s.booking_url AS bookingUrl
                FROM showtime s
                INNER JOIN film f ON f.slug = s.film_slug
                INNER JOIN cinema c ON c.slug = s.cinema_slug
                WHERE s.starts_at >= :dayStart AND s.starts_at < :dayEnd
                  AND s.cinema_slug IN (:cinemas)
                  AND s.status = :status
                  AND (s.reservable_until IS NULL OR s.reservable_until > :now)';
        $params = [
            'dayStart' => $date.' 00:00:00',
            'dayEnd' => date('Y-m-d', strtotime($date.' +1 day')).' 00:00:00',
            'cinemas' => $cinemaSlugs,
            'status' => 'available',
            'now' => $now,
        ];
        $types = ['cinemas' => ArrayParameterType::STRING];

        if ([] !== $excludedFilmSlugs) {
            $sql .= ' AND s.film_slug NOT IN (:excluded)';
            $params['excluded'] = $excludedFilmSlugs;
            $types['excluded'] = ArrayParameterType::STRING;
        }
        if (null !== $version) {
            $sql .= ' AND s.version = :version';
            $params['version'] = $version;
        }

        return $this->getEntityManager()->getConnection()->fetchAllAssociative($sql.' ORDER BY s.starts_at, s.id', $params, $types);
    }

    /**
     * Supprime les séances des cinémas donnés entre $from et $to, sauf celles dont l'identifiant est conservé.
     *
     * @return int nombre de séances supprimées
     */
    public function deleteForCinemasBetween(array $cinemaSlugs, string $from, string $to, array $keepIds): int
    {
        if ([] === $cinemaSlugs) {
            return 0;
        }

        $sql = 'DELETE FROM showtime WHERE cinema_slug IN (:cinemas) AND starts_at >= :from AND starts_at < :to';
        $params = ['cinemas' => $cinemaSlugs, 'from' => $from, 'to' => $to];
        $types = ['cinemas' => ArrayParameterType::STRING];
        if ([] !== $keepIds) {
            $sql .= ' AND id NOT IN (:keep)';
            $params['keep'] = $keepIds;
            $types['keep'] = ArrayParameterType::STRING;
        }

        return (int) $this->getEntityManager()->getConnection()->executeStatement($sql, $params, $types);
    }
}
```

```php
<?php

namespace App\Pathe;

use Psr\Log\LoggerInterface;
use Symfony\Contracts\HttpClient\Exception\DecodingExceptionInterface;
use Symfony\Contracts\HttpClient\Exception\TransportExceptionInterface;
use Symfony\Contracts\HttpClient\HttpClientInterface;

/**
 * Seul point d'accès à l'API (non officielle) de pathe.fr.
 */
class PatheClient
{
    public function __construct(
        private HttpClientInterface $patheClient,
        private LoggerInterface $logger,
        private string $delayMs = '1000',
    ) {
    }

    public function getCities(): array|false
    {
        return $this->get('cities');
    }

    public function getCinemas(): array|false
    {
        return $this->get('cinemas');
    }

    /**
     * @return array|false la liste des films et événements, ou false en cas d'échec
     */
    public function getShows(): array|false
    {
        $data = $this->get('shows');
        if (false === $data) {
            return false;
        }

        return $data['shows'] ?? [];
    }

    /**
     * Programme d'un cinéma : quels films passent quels jours (sans les horaires).
     */
    public function getCinemaProgramme(string $cinemaSlug): array|false
    {
        return $this->get('cinema/'.rawurlencode($cinemaSlug).'/shows');
    }

    /**
     * Séances d'un film dans un cinéma, indexées par date. Pathé renvoie [] quand il n'y en a pas.
     */
    public function getShowtimes(string $showSlug, string $cinemaSlug): array|false
    {
        return $this->get('show/'.rawurlencode($showSlug).'/showtimes/'.rawurlencode($cinemaSlug));
    }

    private function get(string $path): array|false
    {
        usleep((int) $this->delayMs * 1000);

        try {
            $response = $this->patheClient->request('GET', $path, ['query' => ['language' => 'fr']]);
            $status = $response->getStatusCode();

            if (403 === $status || 429 === $status) {
                throw new \RuntimeException(sprintf('Pathé a refusé la requête %s (HTTP %d) : synchronisation interrompue.', $path, $status));
            }

            if (200 !== $status) {
                $this->logger->warning('Réponse inattendue de Pathé', ['path' => $path, 'status' => $status]);

                return false;
            }

            return $response->toArray();
        } catch (TransportExceptionInterface|DecodingExceptionInterface $e) {
            $this->logger->warning('Appel à Pathé en échec', ['path' => $path, 'error' => $e->getMessage()]);

            return false;
        }
    }
}
```

```php
<?php

namespace App\Pathe;

/**
 * Transforme les réponses brutes de Pathé en tableaux prêts à enregistrer.
 */
class PatheMapper
{
    public function mapCity(array $raw): array
    {
        return [
            'slug' => $raw['slug'],
            'name' => $raw['name'],
        ];
    }

    public function mapCinema(array $raw): array
    {
        $theater = $raw['theaters'][0] ?? [];

        return [
            'slug' => $raw['slug'],
            'name' => $raw['name'],
            'citySlug' => $raw['citySlug'],
            'open' => true === ($raw['status'] ?? false),
            'address' => $theater['addressLine1'] ?? null,
            'postalCode' => $theater['addressZip'] ?? null,
            'town' => $theater['addressCity'] ?? null,
            // Pathé nomme « x » la latitude et « y » la longitude.
            'latitude' => isset($theater['gpsPosition']['x']) ? (float) $theater['gpsPosition']['x'] : null,
            'longitude' => isset($theater['gpsPosition']['y']) ? (float) $theater['gpsPosition']['y'] : null,
            'hallCount' => $raw['hallCount'] ?? null,
        ];
    }

    /**
     * @return array|false les champs du film, ou false s'il s'agit d'un événement (pas de séances exploitables)
     */
    public function mapFilm(array $raw): array|false
    {
        if (true !== ($raw['isMovie'] ?? false)) {
            return false;
        }

        // contentRating vaut un objet quand le film est classé, et [] sinon.
        $contentRating = null;
        if (!empty($raw['contentRating']) && isset($raw['contentRating']['description'])) {
            $contentRating = $raw['contentRating']['description'];
        }

        return [
            'slug' => $raw['slug'],
            'title' => $raw['title'],
            'duration' => $raw['duration'] ?? null,
            'releaseDate' => $raw['releaseAt']['FR_FR'] ?? null,
            'genres' => $raw['genres'] ?? [],
            'posterUrl' => $raw['posterPath']['md'] ?? null,
            'contentRating' => $contentRating,
        ];
    }

    /**
     * @param array $raw réponse de /show/{slug}/showtimes/{cinema} : [] ou séances indexées par date
     *
     * @return array liste de séances
     */
    public function mapShowtimes(array $raw): array
    {
        $showtimes = [];
        foreach ($raw as $items) {
            foreach ($items as $item) {
                // Le lien de réservation finit dans un href : on n'accepte que les liens Pathé en HTTPS.
                if (1 !== preg_match('#^https://s\.pathe\.fr/.*/(V\d+S\d+)/#', $item['refCmd'] ?? '', $matches)) {
                    continue;
                }

                $reservableUntil = null;
                if (isset($item['reservabilityEnd'])) {
                    $reservableUntil = (new \DateTimeImmutable($item['reservabilityEnd']))
                        ->setTimezone(new \DateTimeZone('Europe/Paris'))
                        ->format('Y-m-d H:i:s');
                }

                $showtimes[] = [
                    'id' => $matches[1],
                    'startsAt' => $item['time'],
                    'endsAt' => $item['endTime'],
                    'version' => $item['version'],
                    'status' => $item['status'],
                    'bookingUrl' => $item['refCmd'],
                    'reservableUntil' => $reservableUntil,
                    'auditorium' => $item['auditoriumName'] ?? null,
                    'capacity' => $item['auditoriumCapacity'] ?? null,
                ];
            }
        }

        return $showtimes;
    }

    /**
     * Slugs des films programmés au moins un jour entre $from et $to (dates 'Y-m-d' incluses).
     */
    public function showSlugsPlayingBetween(array $programme, string $from, string $to): array
    {
        $slugs = [];
        foreach ($programme['shows'] ?? [] as $slug => $show) {
            foreach (array_keys($show['days'] ?? []) as $day) {
                if ($day >= $from && $day <= $to) {
                    $slugs[] = $slug;
                    break;
                }
            }
        }

        return $slugs;
    }
}
```

```php
<?php

namespace App\Pathe;

use App\Catalog\Entity\Cinema;
use App\Catalog\Entity\City;
use App\Catalog\Entity\Film;
use App\Catalog\Entity\Showtime;
use App\Catalog\Repository\ShowtimeRepository;
use Doctrine\ORM\EntityManagerInterface;
use Psr\Log\LoggerInterface;

/**
 * Copie dans la base les villes, cinémas, films et séances de Pathé.
 */
class CatalogSynchronizer
{
    public function __construct(
        private PatheClient $client,
        private PatheMapper $mapper,
        private EntityManagerInterface $em,
        private ShowtimeRepository $showtimeRepository,
        private LoggerInterface $logger,
    ) {
    }

    /**
     * @param array  $citySlugs villes à synchroniser, ex. ['paris', 'lyon', 'dijon']
     * @param string $today     premier jour synchronisé, format 'Y-m-d'
     * @param int    $days      nombre de jours synchronisés
     *
     * @return array|false ['cities', 'cinemas', 'films', 'showtimes', 'deleted', 'errors'],
     *                     ou false si le référentiel Pathé est inaccessible
     */
    public function synchronize(array $citySlugs, string $today, int $days = 7): array|false
    {
        $stats = ['cities' => 0, 'cinemas' => 0, 'films' => 0, 'showtimes' => 0, 'deleted' => 0, 'errors' => 0];

        $rawCities = $this->client->getCities();
        $rawCinemas = $this->client->getCinemas();
        $rawShows = $this->client->getShows();
        if (false === $rawCities || false === $rawCinemas || false === $rawShows) {
            return false;
        }

        $cities = [];
        foreach ($rawCities as $raw) {
            if (!in_array($raw['slug'], $citySlugs, true)) {
                continue;
            }
            $data = $this->mapper->mapCity($raw);
            $city = $this->em->find(City::class, $data['slug']) ?? (new City())->setSlug($data['slug']);
            $city->setName($data['name']);
            $this->em->persist($city);
            $cities[$data['slug']] = $city;
            ++$stats['cities'];
        }

        $cinemas = [];
        foreach ($rawCinemas as $raw) {
            $data = $this->mapper->mapCinema($raw);
            if (!isset($cities[$data['citySlug']])) {
                continue;
            }
            $cinema = $this->em->find(Cinema::class, $data['slug']) ?? (new Cinema())->setSlug($data['slug']);
            $cinema
                ->setName($data['name'])
                ->setCity($cities[$data['citySlug']])
                ->setAddress($data['address'])
                ->setPostalCode($data['postalCode'])
                ->setTown($data['town'])
                ->setLatitude($data['latitude'])
                ->setLongitude($data['longitude'])
                ->setHallCount($data['hallCount'])
                ->setOpen($data['open']);
            $this->em->persist($cinema);
            $cinemas[$data['slug']] = $cinema;
            ++$stats['cinemas'];
        }

        $films = [];
        foreach ($rawShows as $raw) {
            $data = $this->mapper->mapFilm($raw);
            if (false === $data) {
                continue;
            }
            $film = $this->em->find(Film::class, $data['slug']) ?? (new Film())->setSlug($data['slug']);
            $film
                ->setTitle($data['title'])
                ->setDuration($data['duration'])
                ->setReleaseDate(null !== $data['releaseDate'] ? new \DateTimeImmutable($data['releaseDate']) : null)
                ->setGenres($data['genres'])
                ->setPosterUrl($data['posterUrl'])
                ->setContentRating($data['contentRating']);
            $this->em->persist($film);
            $films[$data['slug']] = $film;
            ++$stats['films'];
        }
        $this->em->flush();

        $lastDay = date('Y-m-d', strtotime($today.' +'.($days - 1).' days'));
        $windowEnd = date('Y-m-d', strtotime($lastDay.' +1 day')).' 00:00:00';

        foreach ($cinemas as $cinemaSlug => $cinema) {
            if (!$cinema->isOpen()) {
                $stats['deleted'] += $this->showtimeRepository->deleteForCinemasBetween([$cinemaSlug], $today.' 00:00:00', $windowEnd, []);
                continue;
            }

            $programme = $this->client->getCinemaProgramme($cinemaSlug);
            if (false === $programme) {
                ++$stats['errors'];
                continue;
            }

            $keptIds = [];
            $complete = true;
            foreach ($this->mapper->showSlugsPlayingBetween($programme, $today, $lastDay) as $showSlug) {
                if (!isset($films[$showSlug])) {
                    continue;
                }

                $rawShowtimes = $this->client->getShowtimes($showSlug, $cinemaSlug);
                if (false === $rawShowtimes) {
                    ++$stats['errors'];
                    $complete = false;
                    continue;
                }

                foreach ($this->mapper->mapShowtimes($rawShowtimes) as $data) {
                    $day = substr($data['startsAt'], 0, 10);
                    if ($day < $today || $day > $lastDay) {
                        continue;
                    }
                    $showtime = $this->em->find(Showtime::class, $data['id']) ?? (new Showtime())->setId($data['id']);
                    $showtime
                        ->setFilm($films[$showSlug])
                        ->setCinema($cinema)
                        ->setStartsAt(new \DateTimeImmutable($data['startsAt']))
                        ->setEndsAt(new \DateTimeImmutable($data['endsAt']))
                        ->setVersion($data['version'])
                        ->setStatus($data['status'])
                        ->setBookingUrl($data['bookingUrl'])
                        ->setReservableUntil(null !== $data['reservableUntil'] ? new \DateTimeImmutable($data['reservableUntil']) : null)
                        ->setAuditorium($data['auditorium'])
                        ->setCapacity($data['capacity']);
                    $this->em->persist($showtime);
                    $keptIds[] = $data['id'];
                    ++$stats['showtimes'];
                }
            }
            $this->em->flush();

            // On ne supprime les séances disparues que si tout le programme du cinéma a pu être lu.
            if ($complete) {
                $stats['deleted'] += $this->showtimeRepository->deleteForCinemasBetween([$cinemaSlug], $today.' 00:00:00', $windowEnd, $keptIds);
            } else {
                $this->logger->warning('Programme incomplet, aucune séance supprimée', ['cinema' => $cinemaSlug]);
            }
        }

        return $stats;
    }
}
```

```php
namespace App\Pathe;
```

```php
/**
 * Lance une synchronisation (commande ou tâche planifiée) puis prévient les pages ouvertes.
 */
class CatalogSyncRunner
{
    public function __construct(
        private CatalogSynchronizer $synchronizer,
        private CatalogUpdatePublisher $publisher,

        private string $defaultCities,
    ) {
    }

    /**
     * @param array $citySlugs villes à synchroniser ; vide = la liste de PATHE_CITIES

    {
        if ([] === $citySlugs) {
            $citySlugs = array_map('trim', explode(',', $this->defaultCities));
        }

        $stats = $this->synchronizer->synchronize($citySlugs, date('Y-m-d'));
        if (false !== $stats) {
            $this->publisher->publish($stats);
        }

        return $stats;
    }
```

```php
namespace App\Catalog\Command;

use Doctrine\DBAL\Connection;
use Symfony\Component\Console\Attribute\AsCommand;
use Symfony\Component\Console\Command\Command;
use Symfony\Component\Console\Input\InputInterface;
use Symfony\Component\Console\Output\OutputInterface;
use Symfony\Component\Console\Style\SymfonyStyle;

#[AsCommand(name: 'catalog:shift-dates', description: 'Décale toutes les séances pour que le premier jour du catalogue devienne aujourd\'hui')]
class ShiftDatesCommand extends Command
{
    public function __construct(private Connection $connection)
    {
        parent::__construct();
    }

    protected function execute(InputInterface $input, OutputInterface $output): int
    {
        $io = new SymfonyStyle($input, $output);

        $firstDay = $this->connection->fetchOne('SELECT MIN(DATE(starts_at)) FROM showtime');
        if (null === $firstDay || false === $firstDay) {
            $io->warning('Aucune séance à décaler.');

            return Command::SUCCESS;
        }

        $days = (int) (new \DateTimeImmutable($firstDay))->diff(new \DateTimeImmutable('today'))->format('%r%a');
        if (0 === $days) {
            $io->success('Le catalogue commence déjà aujourd\'hui.');

            return Command::SUCCESS;
        }

        $this->connection->executeStatement(
            'UPDATE showtime
             SET starts_at = DATE_ADD(starts_at, INTERVAL :days DAY),
                 ends_at = DATE_ADD(ends_at, INTERVAL :days DAY),
                 reservable_until = DATE_ADD(reservable_until, INTERVAL :days DAY)',
            ['days' => $days],
        );

        $io->success(sprintf('Séances décalées de %d jour(s).', $days));

        return Command::SUCCESS;
    }
}
```

```php
#[ORM\Table(name: '`user`')]

{
    #[ORM\Id]
    #[ORM\Column(type: UuidType::NAME, unique: true)]
    private Uuid $id;

    #[ORM\Column(length: 180, unique: true, nullable: true)]
    private ?string $email = null;

    {
        $this->id = Uuid::v7();
        $this->createdAt = new \DateTimeImmutable();
        $this->linkedAccounts = new ArrayCollection();

        return $this->id;
    }

    public function getUserIdentifier(): string
    {
        return $this->id->toRfc4122();
    }

    public function getRoles(): array
    {
        return ['ROLE_USER'];
    }

    public function getEmail(): ?string
    {
        return $this->email;
    }

    {
        $this->email = $email;

        return $this;
    }

    public function getDisplayName(): ?string
    {
        return $this->displayName;
    }

    public function setDisplayName(?string $displayName): static
    {
        $this->displayName = $displayName;

        return $this;
    }

    public function getCreatedAt(): \DateTimeImmutable
    {
        return $this->createdAt;
    }

    /** @return Collection<int, LinkedAccount> */
    public function getLinkedAccounts(): Collection
    {
        return $this->linkedAccounts;
    }

    public function addLinkedAccount(LinkedAccount $linkedAccount): static
    {
        if (!$this->linkedAccounts->contains($linkedAccount)) {
            $this->linkedAccounts->add($linkedAccount);
            $linkedAccount->setUser($this);
        }

        return $this;
    }

    public function removeLinkedAccount(LinkedAccount $linkedAccount): static
    {
        $this->linkedAccounts->removeElement($linkedAccount);

        return $this;
    }
}
```

```php
    public function __construct(ManagerRegistry $registry)
```

```php
     * @return array slugs des films vus par l'utilisateur
     */
    public function findFilmSlugsByUser(string $userId): array
    {
        return $this->createQueryBuilder('s')
            ->select('IDENTITY(s.film) AS slug')
            ->where('s.user = :user')
            ->setParameter('user', $userId, 'uuid')

            ->getSingleColumnResult();

            ->where('s.user = :user')
            ->andWhere('IDENTITY(s.film) = :film')
            ->setParameter('user', $userId, 'uuid')
            ->setParameter('film', $filmSlug)
            ->getQuery()
            ->getOneOrNullResult();
    }
```

```php
<?php

namespace App\Account;

use App\Account\Entity\LinkedAccount;
use App\Account\Entity\User;
use App\Account\Repository\LinkedAccountRepository;
use App\Account\Repository\UserRepository;
use Doctrine\ORM\EntityManagerInterface;

/**
 * Comptes utilisateurs et connexions liées (Google, GitHub, provider local...).
 */
class AccountService
{
    public function __construct(
        private EntityManagerInterface $em,
        private UserRepository $userRepository,
        private LinkedAccountRepository $linkedAccountRepository,
    ) {
    }

    /**
     * Retrouve ou crée le compte correspondant à une identité renvoyée par un provider.
     *
     * @param array $userInfo ['id' => identifiant chez le provider, 'email' => ?string, 'emailVerified' => bool, 'name' => ?string]
     */
    public function loginWithProvider(string $provider, array $userInfo): User
    {
        $linked = $this->linkedAccountRepository->findOneByProviderIdentity($provider, $userInfo['id']);
        if (null !== $linked) {
            return $linked->getUser();
        }

        $user = null;
        // Liaison automatique uniquement si le provider garantit que l'email est vérifié.
        if ($userInfo['emailVerified'] && null !== $userInfo['email']) {
            $user = $this->userRepository->findOneBy(['email' => $userInfo['email']]);
        }

        if (null === $user) {
            $user = new User();
            $user->setEmail($userInfo['emailVerified'] ? $userInfo['email'] : null);
            $user->setDisplayName($userInfo['name'] ?? $userInfo['email']);
            $this->em->persist($user);
        }

        $user->addLinkedAccount($this->newLinkedAccount($provider, $userInfo));
        $this->em->flush();

        return $user;
    }

    /**
     * Lie une identité supplémentaire au compte connecté.
     *
     * @return bool false si cette identité appartient déjà à un autre compte
     */
    public function linkProvider(User $user, string $provider, array $userInfo): bool
    {
        $existing = $this->linkedAccountRepository->findOneByProviderIdentity($provider, $userInfo['id']);
        if (null !== $existing) {
            return $existing->getUser()->getId()->equals($user->getId());
        }

        $user->addLinkedAccount($this->newLinkedAccount($provider, $userInfo));
        if (null === $user->getEmail() && $userInfo['emailVerified'] && null !== $userInfo['email']
            && null === $this->userRepository->findOneBy(['email' => $userInfo['email']])) {
            $user->setEmail($userInfo['email']);
        }
        $this->em->flush();

        return true;
    }

    /**
     * @return bool false si la connexion n'appartient pas à l'utilisateur ou si c'est sa dernière
     */
    public function removeLinkedAccount(User $user, string $linkedAccountId): bool
    {
        if ($user->getLinkedAccounts()->count() <= 1) {
            return false;
        }

        foreach ($user->getLinkedAccounts() as $linkedAccount) {
            if ($linkedAccount->getId()->toRfc4122() === $linkedAccountId) {
                $user->removeLinkedAccount($linkedAccount);
                $this->em->flush();

                return true;
            }
        }

        return false;
    }

    private function newLinkedAccount(string $provider, array $userInfo): LinkedAccount
    {
        return (new LinkedAccount())
            ->setProvider($provider)
            ->setProviderUserId($userInfo['id'])
            ->setEmail($userInfo['email'])
            ->setEmailVerified($userInfo['emailVerified']);
    }
}
```

```php
<?php

namespace App\Account;

use App\Account\Entity\ApiToken;
use App\Account\Entity\User;
use App\Account\Repository\ApiTokenRepository;
use Doctrine\ORM\EntityManagerInterface;
use Symfony\Component\Uid\Uuid;

/**
 * Jetons personnels d'accès à l'API. Seule leur empreinte SHA-256 est stockée.
 */
class ApiTokenService
{
    private const PREFIX = 'mm_';
    private const LIFETIME = '+90 days';

    public function __construct(
        private EntityManagerInterface $em,
        private ApiTokenRepository $apiTokenRepository,
    ) {
    }

    /**
     * @return string le jeton en clair, à montrer une seule fois à l'utilisateur
     */
    public function create(User $user, string $name): string
    {
        $plain = self::PREFIX.bin2hex(random_bytes(32));

        $token = (new ApiToken())
            ->setUser($user)
            ->setName($name)
            ->setTokenHash(hash('sha256', $plain))
            ->setExpiresAt(new \DateTimeImmutable(self::LIFETIME));
        $this->em->persist($token);
        $this->em->flush();

        return $plain;
    }

    public function findUserByToken(#[\SensitiveParameter] string $token): ?User
    {
        // La recherche se fait sur l'empreinte : le jeton en clair n'est jamais comparé ni stocké.
        $apiToken = $this->apiTokenRepository->findOneBy(['tokenHash' => hash('sha256', $token)]);
        if (null === $apiToken || null !== $apiToken->getRevokedAt() || $apiToken->getExpiresAt() <= new \DateTimeImmutable()) {
            return null;
        }

        return $apiToken->getUser();
    }

    /**
     * @return bool false si le jeton n'existe pas ou n'appartient pas à l'utilisateur
     */
    public function revoke(User $user, string $tokenId): bool
    {
        if (!Uuid::isValid($tokenId)) {
            return false;
        }

        $token = $this->em->find(ApiToken::class, $tokenId);
        if (null === $token || !$token->getUser()->getId()->equals($user->getId())) {
            return false;
        }

        $token->setRevokedAt(new \DateTimeImmutable());
        $this->em->flush();

        return true;
    }

    /**
     * @return array jetons actifs : ['id', 'name', 'createdAt', 'expiresAt'] (dates au format 'Y-m-d H:i')
     */
    public function listForUser(User $user): array
    {
        // Les UUID v7 sont triés par date de création.
        $tokens = $this->apiTokenRepository->findBy(['user' => $user, 'revokedAt' => null], ['id' => 'ASC']);

        return array_map(static fn (ApiToken $token) => [
            'id' => $token->getId()->toRfc4122(),
            'name' => $token->getName(),
            'createdAt' => $token->getCreatedAt()->format('Y-m-d H:i'),
            'expiresAt' => $token->getExpiresAt()->format('Y-m-d H:i'),
        ], $tokens);
    }
}
```

```php
<?php

namespace App\Security;

use KnpU\OAuth2ClientBundle\Client\OAuth2ClientInterface;
use League\OAuth2\Client\Provider\ResourceOwnerInterface;
use League\OAuth2\Client\Token\AccessToken;

/**
 * Lit l'identité renvoyée par chaque provider et la ramène à un même format.
 */
class OAuthUserInfoExtractor
{
    /**
     * @return array ['id' => identifiant chez le provider, 'email' => ?string, 'emailVerified' => bool, 'name' => ?string]
     */
    public function extract(string $provider, OAuth2ClientInterface $client, AccessToken $accessToken): array
    {
        $owner = $client->fetchUserFromToken($accessToken);

        return match ($provider) {
            'google', 'local' => $this->fromOpenIdConnect($owner),
            'github' => $this->fromGithub($owner, $client, $accessToken),
            default => throw new \InvalidArgumentException('Provider inconnu : '.$provider),
        };
    }

    private function fromOpenIdConnect(ResourceOwnerInterface $owner): array
    {
        $data = $owner->toArray();

        return [
            'id' => (string) $owner->getId(),
            'email' => $data['email'] ?? null,
            'emailVerified' => true === ($data['email_verified'] ?? null),
            'name' => $data['name'] ?? null,
        ];
    }

    /**
     * GitHub ne fait pas d'OIDC : l'email public de /user n'est pas forcément vérifié.
     * On lit /user/emails et on ne garde que l'email principal ET vérifié.
     */
    private function fromGithub(ResourceOwnerInterface $owner, OAuth2ClientInterface $client, AccessToken $accessToken): array
    {
        $data = $owner->toArray();
        $provider = $client->getOAuth2Provider();
        $emails = $provider->getParsedResponse(
            $provider->getAuthenticatedRequest('GET', 'https://api.github.com/user/emails', $accessToken),
        );

        $email = null;
        foreach (is_array($emails) ? $emails : [] as $entry) {
            if (true === ($entry['primary'] ?? false) && true === ($entry['verified'] ?? false)) {
                $email = $entry['email'];
                break;
            }
        }

        return [
            'id' => (string) $owner->getId(),
            'email' => $email,
            'emailVerified' => null !== $email,
            'name' => $data['name'] ?? $data['login'] ?? null,
        ];
    }
}
```

```php
<?php

namespace App\Security;

use App\Account\AccountService;
use KnpU\OAuth2ClientBundle\Client\ClientRegistry;
use KnpU\OAuth2ClientBundle\Security\Authenticator\OAuth2Authenticator;
use League\OAuth2\Client\Provider\Exception\IdentityProviderException;
use Psr\Http\Client\ClientExceptionInterface;
use Symfony\Bundle\SecurityBundle\Security;
use Symfony\Component\HttpFoundation\RedirectResponse;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\HttpFoundation\Session\FlashBagAwareSessionInterface;
use Symfony\Component\Routing\Generator\UrlGeneratorInterface;
use Symfony\Component\Security\Core\Authentication\Token\TokenInterface;
use Symfony\Component\Security\Core\Exception\AuthenticationException;
use Symfony\Component\Security\Core\Exception\CustomUserMessageAuthenticationException;
use Symfony\Component\Security\Http\Authenticator\Passport\Badge\UserBadge;
use Symfony\Component\Security\Http\Authenticator\Passport\Passport;
use Symfony\Component\Security\Http\Authenticator\Passport\SelfValidatingPassport;
use Symfony\Component\Security\Http\EntryPoint\AuthenticationEntryPointInterface;
use Symfony\Component\Security\Http\Util\TargetPathTrait;

/**
 * Connexion via n'importe quel provider configuré dans knpu_oauth2_client.yaml.
 */
class OAuthAuthenticator extends OAuth2Authenticator implements AuthenticationEntryPointInterface
{
    use TargetPathTrait;

    public function __construct(
        private ClientRegistry $clientRegistry,
        private OAuthProviders $providers,
        private OAuthUserInfoExtractor $extractor,
        private AccountService $accountService,
        private Security $security,
        private UrlGeneratorInterface $urlGenerator,
    ) {
    }

    public function supports(Request $request): ?bool
    {
        if ('app_connect_check' !== $request->attributes->get('_route')) {
            return false;
        }

        // La liaison d'un compte supplémentaire est traitée par ConnectController::check().
        $linking = $request->hasSession() && true === $request->getSession()->get('oauth_link');

        return !($linking && null !== $this->security->getUser());
    }

    public function authenticate(Request $request): Passport
    {
        $provider = (string) $request->attributes->get('provider');
        if (!in_array($provider, $this->providers->enabled(), true)) {
            throw new CustomUserMessageAuthenticationException('Fournisseur de connexion inconnu.');
        }

        $client = $this->clientRegistry->getClient($provider);
        $accessToken = $this->fetchAccessToken($client);

        try {
            $userInfo = $this->extractor->extract($provider, $client, $accessToken);
        } catch (IdentityProviderException|ClientExceptionInterface) {
            throw new CustomUserMessageAuthenticationException('Le fournisseur de connexion ne répond pas. Réessayez.');
        }

        $user = $this->accountService->loginWithProvider($provider, $userInfo);

        return new SelfValidatingPassport(new UserBadge($user->getUserIdentifier(), static fn () => $user));
    }

    public function onAuthenticationSuccess(Request $request, TokenInterface $token, string $firewallName): ?Response
    {
        // Le chemin cible est enregistré par Symfony à partir d'une URL interne de l'application.
        $target = $this->getTargetPath($request->getSession(), $firewallName);

        return new RedirectResponse($target ?? $this->urlGenerator->generate('app_home'));
    }

    public function onAuthenticationFailure(Request $request, AuthenticationException $exception): ?Response
    {
        $message = $exception instanceof CustomUserMessageAuthenticationException
            ? $exception->getMessageKey()
            : 'La connexion a échoué. Réessayez.';

        $session = $request->getSession();
        if ($session instanceof FlashBagAwareSessionInterface) {
            $session->getFlashBag()->add('error', $message);
        }

        return new RedirectResponse($this->urlGenerator->generate('app_login'));
    }

    public function start(Request $request, ?AuthenticationException $authException = null): Response
    {
        return new RedirectResponse($this->urlGenerator->generate('app_login'));
    }
}
```

```php
<?php

namespace App\Security\Controller;

use App\Account\AccountService;
use App\Account\Entity\User;
use App\Security\OAuthProviders;
use App\Security\OAuthUserInfoExtractor;
use KnpU\OAuth2ClientBundle\Client\ClientRegistry;
use League\OAuth2\Client\Provider\Exception\IdentityProviderException;
use Psr\Http\Client\ClientExceptionInterface;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Attribute\Route;

class ConnectController extends AbstractController
{
    public function __construct(
        private ClientRegistry $clientRegistry,
        private OAuthProviders $providers,
        private OAuthUserInfoExtractor $extractor,
        private AccountService $accountService,
    ) {
    }

    #[Route('/connect/{provider}', name: 'app_connect_start', methods: ['GET'])]
    public function start(string $provider, Request $request): Response
    {
        if (!in_array($provider, $this->providers->enabled(), true)) {
            throw $this->createNotFoundException('Fournisseur de connexion inconnu.');
        }

        if ($request->query->getBoolean('link') && null !== $this->getUser()) {
            $request->getSession()->set('oauth_link', true);
        } else {
            $request->getSession()->remove('oauth_link');
        }

        return $this->clientRegistry->getClient($provider)->redirect($this->providers->scopes($provider));
    }

    /**
     * Atteint uniquement pour lier un compte supplémentaire : la connexion elle-même passe par OAuthAuthenticator.
     */
    #[Route('/connect/{provider}/check', name: 'app_connect_check', methods: ['GET'])]
    public function check(string $provider, Request $request): Response
    {
        $user = $this->getUser();
        if (true !== $request->getSession()->remove('oauth_link') || !$user instanceof User) {
            return $this->redirectToRoute('app_login');
        }
        if (!in_array($provider, $this->providers->enabled(), true)) {
            throw $this->createNotFoundException('Fournisseur de connexion inconnu.');
        }

        $client = $this->clientRegistry->getClient($provider);
        try {
            $userInfo = $this->extractor->extract($provider, $client, $client->getAccessToken());
        } catch (\RuntimeException|IdentityProviderException|ClientExceptionInterface) {
            $this->addFlash('error', 'La liaison a échoué. Réessayez.');

            return $this->redirectToRoute('app_profile');
        }

        if ($this->accountService->linkProvider($user, $provider, $userInfo)) {
            $this->addFlash('success', 'Compte '.$provider.' lié.');
        } else {
            $this->addFlash('error', 'Ce compte '.$provider.' est déjà lié à un autre utilisateur.');
        }

        return $this->redirectToRoute('app_profile');
    }
}
```

```php
<?php

namespace App\Planner;

class Geo
{
    private const EARTH_RADIUS_KM = 6371.0;

    /**
     * Distance à vol d'oiseau en kilomètres (formule de Haversine).
     */
    public static function distanceKm(float $lat1, float $lng1, float $lat2, float $lng2): float
    {
        $dLat = deg2rad($lat2 - $lat1);
        $dLng = deg2rad($lng2 - $lng1);
        $a = sin($dLat / 2) ** 2 + cos(deg2rad($lat1)) * cos(deg2rad($lat2)) * sin($dLng / 2) ** 2;

        return self::EARTH_RADIUS_KM * 2 * atan2(sqrt($a), sqrt(1 - $a));
    }
```

```php
<?php

namespace App\Planner;

/**
 * Construit les suites de séances qui s'enchaînent.
 *
 * Une séance occupe la plage [start, end] : start est le début des pubs, end la fin du film.
 */
class ChainBuilder
{
    public const MARGIN_MINUTES = 10;
    public const SPEED_KMH = 15;
    public const ADS_MINUTES = 15;

    public function __construct(private int $maxNodes = 20000)
    {
    }

    /**
     * @param array $showtimes séances candidates : id, filmSlug, cinemaSlug, latitude, longitude,
     *                         start et end (timestamps), plus d'éventuelles clés d'affichage
     * @param int   $count     nombre de films par programme
     * @param bool  $acceptAds accepter d'arriver jusqu'à 15 minutes après le début de séance
     *
     * @return array programmes : ['showtimes' => [...], 'wait' => minutes, 'distance' => km]
     */
    public function build(array $showtimes, int $count, bool $acceptAds): array
    {
        usort($showtimes, static fn (array $a, array $b) => $a['start'] <=> $b['start']);

        $programmes = [];
        $nodes = 0;
        foreach (array_keys($showtimes) as $index) {
            $this->explore([$showtimes[$index]], $index, $showtimes, $count, $acceptAds, $programmes, $nodes);
            if ($nodes >= $this->maxNodes) {
                break;
            }
        }

        return $programmes;
    }

    private function explore(array $path, int $lastIndex, array $showtimes, int $count, bool $acceptAds, array &$programmes, int &$nodes): void
    {
        ++$nodes;
        if (\count($path) === $count) {
            $programmes[] = $this->summarize($path);

            return;
        }

        $last = $path[\count($path) - 1];
        $films = array_column($path, 'filmSlug');
        $total = \count($showtimes);
        for ($next = $lastIndex + 1; $next < $total; ++$next) {
            if ($nodes >= $this->maxNodes) {
                return;
            }
            $candidate = $showtimes[$next];
            if (in_array($candidate['filmSlug'], $films, true) || !$this->canChain($last, $candidate, $acceptAds)) {
                continue;
            }
            $this->explore([...$path, $candidate], $next, $showtimes, $count, $acceptAds, $programmes, $nodes);
        }
    }

    private function canChain(array $previous, array $next, bool $acceptAds): bool
    {
        $latestArrival = $next['start'] + ($acceptAds ? self::ADS_MINUTES * 60 : 0);

        return $this->arrival($previous, $next) <= $latestArrival;
    }

    /**
     * Heure d'arrivée au plus tôt (timestamp) à la séance suivante.
     */
    private function arrival(array $previous, array $next): int
    {
        $arrival = $previous['end'] + self::MARGIN_MINUTES * 60;
        if ($previous['cinemaSlug'] !== $next['cinemaSlug']) {
            $arrival += $this->travelMinutes($previous, $next) * 60;
        }

        return $arrival;
    }

    private function travelMinutes(array $from, array $to): int
    {
        $distance = Geo::distanceKm($from['latitude'], $from['longitude'], $to['latitude'], $to['longitude']);

        return (int) ceil($distance / self::SPEED_KMH * 60);
    }

    private function summarize(array $path): array
    {
        $wait = 0;
        $distance = 0.0;
        $path[0]['lateMinutes'] = 0;
        for ($i = 1, $n = \count($path); $i < $n; ++$i) {
            $arrival = $this->arrival($path[$i - 1], $path[$i]);
            $wait += max(0, $path[$i]['start'] - $arrival);
            $path[$i]['lateMinutes'] = intdiv(max(0, $arrival - $path[$i]['start']), 60);
            if ($path[$i - 1]['cinemaSlug'] !== $path[$i]['cinemaSlug']) {
                $distance += Geo::distanceKm($path[$i - 1]['latitude'], $path[$i - 1]['longitude'], $path[$i]['latitude'], $path[$i]['longitude']);
            }
        }

        return [
            'showtimes' => $path,
            'wait' => intdiv($wait, 60),
            'distance' => round($distance, 2),
        ];
    }
}
```

```php
<?php

namespace App\Planner;

/**
 * Garde les meilleurs programmes, deux à deux différents.
 */
class ProgrammeSelector
{
    /**
     * @param array $programmes programmes produits par ChainBuilder::build()
     *
     * @return array au plus $max programmes, du moins d'attente au plus d'attente (puis du moins de trajet au plus de trajet)
     */
    public function select(array $programmes, int $max = 3): array
    {
        usort($programmes, static fn (array $a, array $b) => [$a['wait'], $a['distance']] <=> [$b['wait'], $b['distance']]);

        $selected = [];
        $filmSets = [];
        foreach ($programmes as $programme) {
            $films = array_column($programme['showtimes'], 'filmSlug');
            sort($films);
            $key = implode('|', $films);
            if (isset($filmSets[$key])) {
                continue;
            }
            $filmSets[$key] = true;
            $selected[] = $programme;
            if (\count($selected) === $max) {
                break;
            }
        }

        return $selected;
    }
}
```

```php
<?php

namespace App\Planner;

use App\Catalog\Repository\CinemaRepository;

/**
 * Transforme le lieu choisi (ville ou position du navigateur) en coordonnées.
 */
class LocationResolver
{
    public function __construct(private CinemaRepository $cinemaRepository)
    {
    }

    /**
     * La position GPS que Pathé donne pour une ville n'est pas fiable (Dijon est placée à 45 km
     * de son centre) : on prend le barycentre des cinémas de la ville.
     *
     * @return array|false ['latitude' => ..., 'longitude' => ...] ou false si la ville n'a aucun cinéma localisé
     */
    public function fromCity(string $citySlug): array|false
    {
        $cinemas = array_filter(
            $this->cinemaRepository->findByCity($citySlug),
            static fn (array $cinema) => null !== $cinema['latitude'] && null !== $cinema['longitude'],
        );
        if ([] === $cinemas) {
            return false;
        }

        return [
            'latitude' => array_sum(array_column($cinemas, 'latitude')) / \count($cinemas),
            'longitude' => array_sum(array_column($cinemas, 'longitude')) / \count($cinemas),
        ];
    }

    /**
     * @param string $json position envoyée par le navigateur, ex. {"lat": 47.32, "lng": 5.04}
     *
     * @return array|false ['latitude' => ..., 'longitude' => ...] ou false si la position est invalide
     */
    public function fromPosition(string $json): array|false
    {
        $data = json_decode($json, true);
        if (!is_array($data) || !isset($data['lat'], $data['lng']) || !is_numeric($data['lat']) || !is_numeric($data['lng'])) {
            return false;
        }

        $latitude = (float) $data['lat'];
        $longitude = (float) $data['lng'];
        if ($latitude < -90 || $latitude > 90 || $longitude < -180 || $longitude > 180) {
            return false;
        }

        return ['latitude' => $latitude, 'longitude' => $longitude];
    }
}
```

```php
<?php

namespace App\Planner;

use App\Account\SeenFilmService;
use App\Catalog\Repository\CinemaRepository;
use App\Catalog\Repository\ShowtimeRepository;

/**
 * Cas d'usage « planifier un marathon », partagé par le site et par l'API.
 */
class PlannerService
{
    public function __construct(
        private CinemaRepository $cinemaRepository,
        private ShowtimeRepository $showtimeRepository,
        private SeenFilmService $seenFilmService,
        private ChainBuilder $chainBuilder,
        private ProgrammeSelector $programmeSelector,
    ) {
    }

    /**
     * @param array  $criteria 'date' (Y-m-d), 'latitude', 'longitude', 'radius' (km), 'films' (nombre),
     *                         'version' (ou null), 'acceptAds' (bool)
     * @param string $userId   identifiant de l'utilisateur (ses films déjà vus sont exclus)
     *
     * @return array|false ['programmes' => [...], 'reason' => null|'not_enough_programmes'|'no_programme'],
     *                     ou false si aucune séance ne correspond au lieu et à la date
     */
    public function plan(array $criteria, string $userId): array|false
    {
        $radius = $criteria['radius'] ?? 10;
        $films = $criteria['films'] ?? 3;

        $cinemaSlugs = [];
        foreach ($this->cinemaRepository->findOpenWithCoordinates() as $cinema) {
            if (Geo::distanceKm($criteria['latitude'], $criteria['longitude'], $cinema['latitude'], $cinema['longitude']) <= $radius) {
                $cinemaSlugs[] = $cinema['slug'];
            }
        }

        $now = new \DateTimeImmutable();
        $rows = $this->showtimeRepository->findCandidates(
            $criteria['date'],
            $cinemaSlugs,
            $this->seenFilmService->getSeenFilmSlugs($userId),
            $criteria['version'] ?? null,
            $now->format('Y-m-d H:i:s'),
        );
        if ([] === $rows) {
            return false;
        }

        $showtimes = [];
        foreach ($rows as $row) {
            $row['start'] = strtotime($row['startsAt']);
            $row['end'] = strtotime($row['endsAt']);
            $showtimes[] = $row;
        }

        $programmes = $this->programmeSelector->select(
            $this->chainBuilder->build($showtimes, $films, $criteria['acceptAds'] ?? false),
        );

        $reason = null;
        if ([] === $programmes) {
            $reason = 'no_programme';
        } elseif (\count($programmes) < 3) {
            $reason = 'not_enough_programmes';
        }

        return [
            'programmes' => array_map([$this, 'format'], $programmes),
            'reason' => $reason,
        ];
    }

    private function format(array $programme): array
    {
        foreach ($programme['showtimes'] as $i => $showtime) {
            $programme['showtimes'][$i]['startTime'] = date('H:i', $showtime['start']);
            $programme['showtimes'][$i]['endTime'] = date('H:i', $showtime['end']);
        }
        $programme['filmSlugs'] = array_column($programme['showtimes'], 'filmSlug');

        return $programme;
    }
}
```

```php
    {
```

```php
        if (!$this->seenFilmService->markSeen($user->getUserIdentifier(), $slug)) {

        }

    {
        $this->denyUnlessValidToken($request);
        $this->seenFilmService->unmarkSeen($user->getUserIdentifier(), $slug);

        return $this->respond($request, [$slug], false);
    }

    #[Route('/programmes/seen', name: 'app_programme_seen', methods: ['POST'])]
    public function markProgrammeSeen(Request $request, #[CurrentUser] User $user): Response
    {
        $this->denyUnlessValidToken($request);
        $slugs = array_values(array_filter($request->request->all('films'), 'is_string'));
        $this->seenFilmService->markAllSeen($user->getUserIdentifier(), $slugs);

        return $this->respond($request, $slugs, true);
    }

    private function denyUnlessValidToken(Request $request): void
    {
        if (!$this->isCsrfTokenValid('seen-film', $request->request->getString('_token'))) {
            throw $this->createAccessDeniedException('Jeton CSRF invalide.');
        }
    }

    /**
     * Avec Turbo : un flux qui remplace tous les boutons des films concernés.
     * Sans JavaScript : retour sur la fiche du film (ou sur le profil pour un programme).
     */
    private function respond(Request $request, array $slugs, bool $seen): Response

        }

        if (1 === \count($slugs)) {
            return $this->redirectToRoute('app_film_show', ['slug' => $slugs[0]]);
        }

        return $this->redirectToRoute('app_home');
```

```js
 * Remplit le champ caché « position » du formulaire avec la position du navigateur, en JSON.

export default class extends Controller {
    static targets = ['position', 'status'];

    locate() {
        if (!navigator.geolocation) {
```

```php
<?php

namespace App\Web\Controller;

use App\Account\AccountService;
use App\Account\ApiTokenService;
use App\Account\Entity\User;
use App\Account\SeenFilmService;
use App\Security\OAuthProviders;
use Symfony\Bundle\FrameworkBundle\Controller\AbstractController;
use Symfony\Component\HttpFoundation\Request;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\Routing\Attribute\Route;
use Symfony\Component\Security\Http\Attribute\CurrentUser;

#[Route('/profile')]
class ProfileController extends AbstractController
{
    public function __construct(
        private SeenFilmService $seenFilmService,
        private AccountService $accountService,
        private ApiTokenService $apiTokenService,
        private OAuthProviders $oauthProviders,
    ) {
    }

    #[Route('', name: 'app_profile', methods: ['GET'])]
    public function index(#[CurrentUser] User $user): Response
    {
        return $this->renderProfile($user, null);
    }

    #[Route('/connections/{id}/remove', name: 'app_profile_connection_remove', methods: ['POST'])]
    public function removeConnection(string $id, Request $request, #[CurrentUser] User $user): Response
    {
        if (!$this->isCsrfTokenValid('profile-connection', $request->request->getString('_token'))) {
            throw $this->createAccessDeniedException('Jeton CSRF invalide.');
        }

        if (!$this->accountService->removeLinkedAccount($user, $id)) {
            $this->addFlash('error', 'Impossible de retirer cette connexion : c\'est votre dernière connexion, ou elle n\'existe pas.');
        }

        return $this->redirectToRoute('app_profile');
    }

    #[Route('/tokens', name: 'app_profile_token_create', methods: ['POST'])]
    public function createToken(Request $request, #[CurrentUser] User $user): Response
    {
        if (!$this->isCsrfTokenValid('api-token', $request->request->getString('_token'))) {
            throw $this->createAccessDeniedException('Jeton CSRF invalide.');
        }

        $name = trim($request->request->getString('name'));
        if ('' === $name || mb_strlen($name) > 100) {
            $this->addFlash('error', 'Donnez un nom au jeton (100 caractères au plus).');

            return $this->redirectToRoute('app_profile');
        }

        // Pas de redirection : le jeton en clair n'est affiché qu'une fois et n'est jamais mis en session.
        return $this->renderProfile($user, $this->apiTokenService->create($user, $name));
    }

    #[Route('/tokens/{id}/revoke', name: 'app_profile_token_revoke', methods: ['POST'])]
    public function revokeToken(string $id, Request $request, #[CurrentUser] User $user): Response
    {
        if (!$this->isCsrfTokenValid('api-token', $request->request->getString('_token'))) {
            throw $this->createAccessDeniedException('Jeton CSRF invalide.');
        }

        if (!$this->apiTokenService->revoke($user, $id)) {
            $this->addFlash('error', 'Jeton introuvable.');
        }

        return $this->redirectToRoute('app_profile');
    }

    private function renderProfile(User $user, #[\SensitiveParameter] ?string $newToken): Response
    {
        $linkedProviders = [];
        foreach ($user->getLinkedAccounts() as $linkedAccount) {
            $linkedProviders[] = $linkedAccount->getProvider();
        }

        return $this->render('profile/index.html.twig', [
            'user' => $user,
            'seenFilms' => $this->seenFilmService->listSeenFilms($user->getUserIdentifier()),
            'providersToLink' => array_values(array_diff($this->oauthProviders->enabled(), $linkedProviders)),
            'tokens' => $this->apiTokenService->listForUser($user),
            'newToken' => $newToken,
        ]);
    }
}
```

```php
<?php

namespace App\Security;

use App\Account\ApiTokenService;
use Symfony\Component\Security\Core\Exception\BadCredentialsException;
use Symfony\Component\Security\Http\AccessToken\AccessTokenHandlerInterface;
use Symfony\Component\Security\Http\Authenticator\Passport\Badge\UserBadge;

/**
 * Authentifie les appels à l'API grâce à un jeton personnel (en-tête Authorization: Bearer).
 */
class ApiTokenHandler implements AccessTokenHandlerInterface
{
    public function __construct(private ApiTokenService $apiTokenService)
    {
    }

    public function getUserBadgeFrom(#[\SensitiveParameter] string $accessToken): UserBadge
    {
        $user = $this->apiTokenService->findUserByToken($accessToken);
        if (null === $user) {
            throw new BadCredentialsException('Jeton invalide, expiré ou révoqué.');
        }

        return new UserBadge($user->getUserIdentifier(), static fn () => $user);
    }
}
```

```php
<?php

namespace App\Api\EventListener;

use Symfony\Component\EventDispatcher\Attribute\AsEventListener;
use Symfony\Component\HttpFoundation\JsonResponse;
use Symfony\Component\HttpFoundation\Response;
use Symfony\Component\HttpKernel\Event\ExceptionEvent;
use Symfony\Component\HttpKernel\Exception\HttpExceptionInterface;

/**
 * Transforme les erreurs de l'API en application/problem+json, sans jamais exposer de détail technique.
 */
#[AsEventListener]
class ApiExceptionListener
{
    public function __invoke(ExceptionEvent $event): void
    {
        if (!str_starts_with($event->getRequest()->getPathInfo(), '/api/')) {
            return;
        }

        $exception = $event->getThrowable();
        $status = $exception instanceof HttpExceptionInterface ? $exception->getStatusCode() : 500;
        $problem = [
            'type' => 'about:blank',
            'title' => Response::$statusTexts[$status] ?? 'Erreur',
            'status' => $status,
        ];
        if ($exception instanceof HttpExceptionInterface && '' !== $exception->getMessage()) {
            $problem['detail'] = $exception->getMessage();
        }

        $event->setResponse(new JsonResponse($problem, $status, ['Content-Type' => 'application/problem+json']));
    }
}
```

`README.md` :

````markdown
# Marathon ciné — defensive PHP workshop

A Symfony 8.1 application that plans movie marathons from Pathé showtimes. It
is the starting point of a workshop on defensive programming in PHP: the code
is clean, tested and secure, but its contracts are deliberately implicit
(arrays, scalars, `false|result` returns). The exercises are in
[`docs/exercices.md`](docs/exercices.md) (French).

## Requirements

Docker with Compose v2 and `make`. Nothing else runs on the host.

## Getting started

```bash
make up        # build and start FrankenPHP, MySQL, the worker and the local OIDC provider
make db-load   # reset the database and import the Pathé catalogue (data/catalog.sql.gz)
```

Open https://localhost (accept the local certificate) and sign in with
**Local provider**: any username works, no Internet connection needed.

## Optional: real providers

Create OAuth apps and set the credentials in `.env.local`:

| Provider | Callback URL | Variables |
|----------|--------------|-----------|
| Google | `https://localhost/connect/google/check` | `OAUTH_GOOGLE_CLIENT_ID`, `OAUTH_GOOGLE_CLIENT_SECRET` |
| GitHub | `https://localhost/connect/github/check` | `OAUTH_GITHUB_CLIENT_ID`, `OAUTH_GITHUB_CLIENT_SECRET` |

Then list them in `OAUTH_PROVIDERS` (e.g. `local,github,google`).

## Everyday commands

| Command | Purpose |
|---------|---------|
| `make test` | PHPUnit (creates the test database if needed) |
| `make phpstan` | PHPStan, level 5 (must stay green) |
| `make phpstan-max` | PHPStan, max level against the baseline (workshop progress) |
| `make cs` | PHP-CS-Fixer (`@Symfony`) |
| `make sync` | Sync the catalogue from pathe.fr (network; `c="--city=dijon"`) |
| `make db-dump` | Write `data/catalog.sql.gz` from the current catalogue |
| `make sh` / `make console c="…"` | Shell / Symfony console in the PHP container |

The API is documented at https://localhost/api/doc; create a personal token
from your profile page.

## Production image

`docker build --target prod .` builds a production image without development
tools, running as a non-root user.
````
